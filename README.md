# Power Play Entertainment — Offline Landing Page Designs

Open **index.html** in Chrome to compare both designs. No installation or internet connection is needed.

- **wedding.html** — Premium wedding entertainment landing page.
- **corporate.html** — Corporate entertainment landing page.
- **styles.css** — Shared, class-based styling; no inline CSS.
- **main.js** — Mobile navigation, review carousel and inquiry-form demonstration.
- **assets/** — Local PPE photographs, logo and locally hosted Anton/Montserrat fonts.

Both pages include the full page structure, audience-specific English copy, real PPE imagery, 20 genuine Google review excerpts, FAQs and separate inquiry experiences. The carousel supports buttons, swipe/scroll and keyboard navigation. It does not autoplay. Layouts respond to desktop, tablet and mobile screens and respect reduced-motion preferences.

The two-step inquiry form is at the top of each page, inside the hero. Contextual CTAs after each major section and a mobile sticky CTA return visitors to that same form. Review cards use the official full-color Google G asset, bundled locally from Google's gstatic domain. Responsive checks cover 320px and 390px phones, 768px tablets, 1024px landscape tablets, and a 1440px desktop.

## Preview limitations

- This is a local design prototype. The inquiry forms validate and demonstrate the intended flow but do not send or save personal information. Dedicated Contact Form 7 forms belong to the later WordPress implementation.
- The wedding starting price of **$2,300** comes from the supplied client email and remains an assumption pending client confirmation. Corporate budget bands are proposed qualification options, not package prices.
- The top preview-navigation bar is for reviewing these designs; it is not intended for the paid-ad landing pages.
- No changes have been made to the live WordPress site for this offline prototype.
- External phone, Google, privacy-policy and terms links are labeled or identifiable; external web links require internet access. Local design and interactions do not.
